# TA0003 - The TODO comments contains a task ID that requires to be reported

## Cause

## Rule description
The comment contains a `TODO` token line and it needs to be reported because the
`.editorconfig` contains `todo_analyzer.report_tasks` contains a comma separated list
of task identifier that needs to be reported, for example:

```
todo_analyzer.report_tasks = 77, 99, 134
```

## How to fix violations
Address and remove the TODO comment or amend the `.editorconfig`.

This is an example of incorrect `TODO` comment:
```csharp
// TODO [#77] This function has not been implemented yet.
int MyFunction(){ return 0; }
```

The violation can be fixed like this:
```csharp
int MyFunction(){ return 0; }
```
