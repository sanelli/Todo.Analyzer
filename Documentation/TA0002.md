# TA0002 - TODO Comment exists

## Cause

## Rule description
The comment contains a `TODO` token line and it needs to be reported because the
`.editorconfig` contains `todo_analyzer.always_report` which is set to either
`true`, `yes`, `1` or `enable`, for example:

```
todo_analyzer.always_report = true
```

## How to fix violations
Address and remove the TODO comment or amend the `.editorconfig`.

This is an example of incorrect `TODO` comment:
```csharp
// TODO [#77] Function needs to be implemented
int MyFunction(){ return 0; }
```

The violation can be fixed like this:
```csharp
int MyFunction(){ return 0; }
```
